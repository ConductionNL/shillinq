# Integrations

:::note Placeholder
This is a structural stub for the canonical product-pages layout. Per-integration pages land via [issue #78](https://github.com/ConductionNL/shillinq/issues/78).

Planned integrations: OpenRegister (canonical data backbone), OpenConnector (source sync), DocuDesk (invoice and contract generation), Peppol / NLCIUS (e-invoicing transport), SBR / Digipoort (Belastingdienst filing), CAMT.053 bank-statement import, Nextcloud Contacts (counterparties), OAuth / Keycloak (SSO).

Each page covers what the integration does, how to connect it, what configuration each side needs, and which Shillinq features depend on it.
