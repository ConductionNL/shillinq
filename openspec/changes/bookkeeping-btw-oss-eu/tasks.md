- [x] Task 11: Implement invoice-creation guard per REQ-OSS-001 (destination-country VAT rate resolution): when invoice destination is EU non-NL and customerType is b2c, query EuVatRate table for the invoice date + rate category; if found, populate ossContext and materialise GL posting to per-country OSS accounts; if not found, block save with `oss.rate.missing`.
- [x] Task 12: Implement threshold monitoring per REQ-OSS-002 (EUR 10,000 B2C-to-EU annual counter): on invoice save, if OSS-eligible, increment OssThresholdCounter; when counter approaches EUR 10,000 (within EUR 100), show non-blocking warning; when crossed (and not yet registered), block save with `oss.threshold.crossed` until bookkeeper registers, marks `voluntaryBelowThreshold`, or splits invoice.
- [x] Task 13: Implement ledger segregation per REQ-OSS-003 (per-country OSS accounts): when posting an OSS invoice to a destination country for the first time, auto-create accounts `8xxx Omzet OSS {countryCode}` (revenue) and `1xxx BTW af te dragen OSS {countryCode}` (payable) from chart-of-accounts templates. Book invoice GL entry to these per-country accounts, never to domestic `8100` or `1500` accounts.
- [x] Task 14: Implement VAT-rate resolution at invoice time per REQ-OSS-001: create `OssRateResolver` service (or declarative aggregation) that queries EuVatRate for (countryCode, invoiceDate, rateCategory) and returns the rate percentage + EuVatRate row id (tedbRateVersion). Fallback: if no rate found, populate ossContext with null and block save.
- [x] Task 15: Implement quarterly OSS return generation per REQ-OSS-004: create `OssReturnGenerator` service that, for a given quarter, aggregates all OSS-eligible invoices + credit notes grouped by (destinationCountry, rateCategory), sums taxable bases and VAT amounts, and generates a draft OssReturn record with line items. Query must complete within 5 seconds.
- [x] Task 16: Implement OSS return XSD/CSV generation per REQ-OSS-005: create `OssReturnFormatter` service that takes a draft OssReturn and produces a Belastingdienst OSS XSD-compliant XML file (or CSV fallback) with seller OSS-identifier, period YYYY-Qn, ISO 3166-1 country codes, EUR amounts with 2 decimals, seller IBAN. Validate against current Belastingdienst XSD; archive on OssReturn record.
- [x] Task 17: Implement B2B / B2C fork at invoice time per REQ-OSS-006 / REQ-OSS-015: in invoice creation logic, check Counterparty.customerType (b2b / b2c) and Counterparty.vatValidationStatus. If b2b + valid VAT-ID, route to reverse-charge (0% VAT, ICP-opgaaf path). If b2c or (b2b + invalid VAT-ID), route to OSS and warn if VAT-ID mismatch.
- [x] Task 18: Implement audit trail for applied VAT rates per REQ-OSS-007: persist EuVatRate row id (tedbRateVersion) on every OSS invoice ossContext.appliedVatRate. When TEDB is refreshed and rates change, historic invoices retain their tedbRateVersion reference and still display the originally applied rate (not the new rate from updated EuVatRate rows).
- [x] Task 19: Implement payment reconciliation per REQ-OSS-008: create `OssPaymentReconciliation` service that matches bank transactions (amount, date, IBAN) to OssReturn records; transition OssReturn status to `paid` on match. - [x] Task 20: Implement voluntary opt-in below threshold per REQ-OSS-009: allow bookkeeper to register for OSS via UI with voluntaryBelowThreshold flag (without hitting EUR 10,000 threshold). Once active, lock-in period is enforced: bookkeeper cannot disable OSS until 3 calendar years have passed (Article 369a paragraph 3). Disable attempt blocks with explanation.
- [x] Task 21: Implement correction-return workflow per REQ-OSS-010: allow bookkeeper to create a new OssReturn of type `correction` linked to an original period via correctsPeriod field. ## Standards & Sources

- Council Directive 2006/112/EC (VAT Directive), in particular Articles 358a–369x (the Union scheme), Article 61 (3-year correction window).
- Council Implementing Regulation (EU) 282/2011 as amended by 2019/2026 (place-of-supply rules for distance sales of goods and TBE services).
- Council Regulation (EU) 904/2010 on administrative cooperation and combating fraud in the field of VAT (redistribution framework).
- Belastingdienst publication "One-stop-shopregeling" (mijnbelastingdienst.nl/zakelijk/btw/eu-regeling).
- Belastingdienst XSD for OSS upload (current version on belastingdienst.nl/wps/wcm/connect/.../OSS_VAT_Return).
- European Commission Taxes in Europe Database (TEDB) v3 REST endpoint (ec.europa.eu/taxation_customs/tedb).
- Article 273 Directive 2006/112/EC (penalties for VAT non-compliance, up to 50% of unpaid VAT).
