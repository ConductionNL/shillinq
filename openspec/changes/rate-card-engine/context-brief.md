# Rate Card Engine (multi-tier, effective-dated)

## Purpose

Multi-tier rate hierarchy (user / role / project / client / blended); effective-dated rates.

## Priority & Demand

- **Priority:** P0-must
- **Demand evidence:** 21/26 competitors
- **Dependencies:** none
