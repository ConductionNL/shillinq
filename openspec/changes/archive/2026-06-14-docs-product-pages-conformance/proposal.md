# Proposal: docs-product-pages-conformance

## Summary

An audit on 2026-05-13 found shillinq's `docs/` directory partially conformant to the canonical product-pages spec that recently shipped to the Conduction design system (`preview/product-pages/`). This change brings shillinq's documentation into full Tier-1 (structural) and Tier-2 (configuration) conformance: renaming folders, moving files, fixing em-dash violations, adding stub placeholder pages for Tier-3 content areas, and wiring up the redocusaurus API docs preset and the `nl` locale so the design-system preset's full feature set is active.

## Motivation

The Conduction design-system preset (`@conduction/docusaurus-preset`) defines a canonical product-pages layout with specific folder structure (`user-guide/`, `Features/`, `Technical/`, `UseCases/`, `Integrations/`), an API Documentation link powered by redocusaurus, and Dutch/English locale support (ADR-030). Shillinq's docs were scaffolded before the canonical spec landed and diverged on folder names (`tutorials/` instead of `user-guide/`), file locations (`FEATURES.md` at root instead of `Features/index.md`), locale config (only `en`), and API docs wiring (redocusaurus not configured). Bringing shillinq into conformance keeps the fleet consistent and makes the docs site match the reference implementation (openregister).

## Affected Projects

- [x] Project: `shillinq` — `docs/` folder structure, `docusaurus.config.js`, `package.json`, em-dash fixes in `.md` content files

## Scope

### In Scope

- Rename `docs/tutorials/` to `docs/user-guide/` (keeping `admin/` and `user/` subdirs and all existing content unchanged; folder rename only).
- Move `docs/FEATURES.md` to `docs/Features/index.md`; fix any em-dash characters during the move.
- Move `docs/ARCHITECTURE.md` to `docs/Technical/architecture.md`; fix em-dash characters during the move.
- Create `docs/UseCases/index.md` and `docs/Integrations/index.md` as `draft: true` frontmatter-only stubs referencing issue #78.
- Create `docs/installation.md` with real prerequisite + install steps mirroring `openregister/docs/installation.md` structure.
- Fix em-dash violations in `docs/intro.md` (3 hits) and in the moved `docs/Technical/architecture.md` (5 hits in ADR list titles).
- Add `redocusaurus@^2.0.0` to `docs/package.json` dependencies.
- Configure redocusaurus in `docs/docusaurus.config.js`: preset entry, mount at `/api`, fed by `static/oas/shillinq.json` (placeholder; will 404 until issue #80 ships).
- Add an "API Documentation" navbar link pointing to `/api` (positioned right of "Documentation").
- Re-enable the `nl` locale in `docs/docusaurus.config.js`: `locales: ['en', 'nl']` with comment noting dependency on issue #79.
- Verify `docs/sidebars.js` remains compatible (currently autogenerated; no change needed).

### Out of Scope

- Content rewrite of the 11 existing tutorial pages (filled upstream in commit #76; only folder rename).
- Dutch (`nl`) markdown translation files (tracked by issue #79).
- OpenAPI JSON authoring (tracked by issue #80).
- Real UseCases or Integrations content (tracked by issue #78).
- PR creation, merge, or archive process tasks.

## Approach

All changes are mechanical file operations plus config edits:

1. Git `mv` the `tutorials/` folder to `user-guide/` and the root `.md` files to their canonical locations.
2. Run a targeted em-dash search-and-replace (using the Edit tool, not sed/awk) across the moved files and `intro.md`.
3. Edit `docs/package.json` to add `redocusaurus`.
4. Edit `docs/docusaurus.config.js` to add the redocusaurus preset block, the API nav link, and `nl` locale.
5. Create the two stub pages with minimal frontmatter.
6. Create `docs/installation.md` based on the openregister reference.

No backend code, schema, or PHP changes.

## New Dependencies

- `redocusaurus@^2.0.0` — added to `docs/package.json` dependencies (matches version pinned by `openregister/docs/package.json`).

## Impact

- `docs/tutorials/` renamed to `docs/user-guide/` — all 11 tutorial pages move; existing deep-links using `/tutorials/` will redirect if the preset ships canonical redirects, otherwise they 404 until issue #79 wires them.
- `docs/FEATURES.md` removed (content preserved at `docs/Features/index.md`).
- `docs/ARCHITECTURE.md` removed (content preserved at `docs/Technical/architecture.md`).
- `docs/docusaurus.config.js` updated with new preset entry and nav link.
- `docs/package.json` updated with new dependency.

## Cross-Project Dependencies

None. The change reads `openregister/docs/` as a reference implementation but does not modify it.

## Risks

### Risk 1: `nl` locale breaks SSR build

**Severity:** Low — **Mitigation:** No NL markdown ships in this change; the locale config only declares the locale. If enabling `nl` in the config (without actual `.md` files) causes Docusaurus SSR to fail, the locale change is reverted with a comment and a reference to issue #79. The rest of the change passes acceptance unchanged.

### Risk 2: `tutorials/` rename breaks existing deep-links

**Severity:** Low — **Mitigation:** These are docs-site links only, not API routes. Deep-links are already unstable (the spec mandates `user-guide/`); a redirect rule can be added later. Issue #81 tracks any residual `{{TODO}}` cleanup.

## Rollback Strategy

Revert the commit on the `feature/docs-product-pages-conformance` branch. All changes are in `docs/` and `openspec/`; no backend code is touched. `git revert <commit>` restores the original folder layout immediately.
